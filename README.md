# bt2-manager2

تطبيق محلي لإدارة MikroTik HotSpot، مبني بـGo وReact/TypeScript وSQLite، مع غلاف سطح مكتب Windows عبر Wails. الواجهة عربية RTL، والخادم المحلي يستمع على loopback فقط. كلمات مرور الراوتر لا تُحفظ؛ تُستخدم خلال جلسة الاتصال فقط.

## التشغيل في وضع الويب المحلي

المتطلبات: Go 1.23 أو أحدث، وNode.js 22 أو أحدث.

```powershell
cd web
npm ci
npm run build
cd ..
go run ./cmd/bt2-manager2
```

افتح <http://127.0.0.1:8787>. قاعدة البيانات ومفتاح تشفير كلمات مرور القسائم يُنشآن في مجلد إعداد المستخدم (`BT2Manager2`). لا تضع مجلد البيانات أو المفتاح في Git.

## بناء تطبيق Windows

تحتاج Windows 10/11 وGo 1.23+ وNode.js 22+ وMicrosoft Edge WebView2 Runtime. من جذر المستودع:

```powershell
./scripts/build-windows.ps1
```

ينتج الملف `build/BT2Manager2.exe` بواجهة مضمّنة؛ لا يحتاج Node.js بعد البناء. يمكن أيضاً تشغيل خادم الويب محلياً باستخدام `./scripts/run-web.ps1`.

## الموجود حالياً

- اتصال RouterOS ببيانات مؤقتة في الذاكرة، وقراءة الهوية والإصدار وملفات/مستخدمي HotSpot.
- SQLite ومهاجرات، تعريف باقات HotSpot وموزعين، توليد دفعات مع نتائج جزئية، وتشفير كلمات مرور القسائم محلياً.
- سجل تخصيص/تحويل/إرجاع للمخزون؛ لا يوجد POS مالي أو بيع/تحصيل.
- دعم الكتابة على الراوتر محدود حالياً بإنشاء دفعات HotSpot وتعطيل قسيمة محفوظة بعد مطابقة الراوتر. اختبارات التكامل على أجهزة RouterOS v6 وv7 مطلوبة قبل الاعتماد التشغيلي.

استوديو البطاقات/PDF، مزامنة User Manager للقراءة عبر v6/v7، النسخ الاحتياطي والاستعادة، وإكمال اختبارات التوافق والأمان ما تزال ضمن المهام التالية وليست مكتملة بعد. تابع [خطة التطوير وقرارات النطاق](docs/DEVELOPMENT_PLAN_AR.md).
